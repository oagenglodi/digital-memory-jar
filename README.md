# Digital Memory Jar 🫙

## About the Project
Digital Memory Jar is a beginner-friendly web application that allows users to save their happy moments and revisit them whenever they need a little reminder of the good things in life.

## Built With
- HTML
- CSS
- JavaScript
- Local Storage

## Features
- Save personal memories
- Store memories in the browser
- Revisit saved moments
